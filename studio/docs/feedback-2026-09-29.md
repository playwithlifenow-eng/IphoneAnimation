This revision implements Matt’s requested canvas, hierarchy, deletion, layout and component-import changes on `studio/ux-canvas-v2`, based on `studio/broad-v1` at `2288f03c6db7d808969034775d48455d23a6cd03`. All changes are under `studio/`.

## Requested behavior and implementation

| Request | Delivered behavior |
| --- | --- |
| Infinite canvas | An unbounded pan/zoom workspace, visible overflow outside the page, cursor-centred wheel zoom and Fit bounds. Page/export height derives from content; profile height is only a minimum. No manual height adjustment is needed to place another section below. |
| Second frame/section | Compose → Add section below creates a full-width frame immediately after current content, with desktop/mobile positions and selection brought into view. |
| Parent/child and grid | Properties starts with Parent and Detach. Frames expose Child text/frame/button, free/vertical/horizontal/grid layouts, grid columns, gap, padding and automatic height. The nested layer tree supports drag-to-parent, detach, reordering and deletion. |
| Undo relationships | Header Undo/Redo and keyboard shortcuts reverse relationship creation, removal and grouping. Relationship rows also have Remove. |
| Delete Takes/copy/variants/components | Every listed item has a deletion control. Copy deletion preserves already placed text; component shelf deletion preserves placed instances. Deletion can be undone. |
| Recognisable Takes | Cards immediately render their stored document, profile, playhead and controlled inputs. Names edit inline. Open for editing loads that version; Mark preferred marks the reference without replacing the canvas. |
| More canvas space | Two compact top rows; default 310px library with 260–480px resizing and persistent collapse; collapsible Properties; transport, property, Add key, pose name and Record pose share a choreography row. |
| Clearer terminology | Inspector is now Properties. The old Base composition panel is replaced by a scope badge beside profile controls. Alignment buttons explain that they align selected elements, rather than indenting text. |
| Copy architecture | Optional H1/H2/H3/body/microcopy/CTA roles and section labels, with role typography on insertion and semantic heading output. Existing typography stays custom unless a role is chosen. |
| Framer import | Paste Copy Import or a public component module URL, compile, preview, add to shelf, insert and edit props. Imported JavaScript is included in portable projects and standalone runtime ZIPs. |

## Implementation boundaries

The canvas has no authoring boundary. Responsive pages still have a defined width; objects beside/above the page remain on the editing pasteboard rather than expanding the exported page sideways.

Reparenting preserves position/size across profiles for static, unrotated elements. Flow/grid parents then arrange their children. Animated or rotated reparenting is rejected explicitly until coordinate/track conversion is supported.

Framer imports use `unframer` and run in a sandboxed iframe. Primitive property controls and an optional JSON props object are editable. Imported internals are not decomposed into editable Studio layers. Framer CMS/project/editor context is not recreated; external assets and data may still require their hosts. Compatibility must be checked per component. The browser fixture imports the real public module `https://framer.com/m/Button-5TDo.js` and checks the independent export.

3D canvases measure their unscaled layout size, so editor zoom and Take thumbnails do not shrink models twice. Take thumbnails render visible cards on demand to avoid keeping an entire library of WebGL scenes active. They are previews of saved state, not fabricated screenshots or recorded videos.
